`IMPLEMENTED` means an existing deterministic scenario and one or more
post-run evaluators are linked. It does not mean that the requirement has
passed for every engine profile. Test implementation status comes from
`MINI-FADEC-TEST-CASES` version `0.1.0`: `PARTIAL_AUTOMATION` is not accepted as
complete formal evidence. In particular, the ambient scenarios verify SIL
input propagation and bounded behavior but not physical ambient sensitivity.
